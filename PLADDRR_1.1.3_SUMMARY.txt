### 1. PointProcess$to_textgrid_vuv() ✅ COMPLETE
**Status**: Fully functional
**Location**: R/pointprocess-r6.R (lines 554-628)
**C++ Wrapper**: src/pointprocess_wrappers.cpp (lines 644-663)
**Purpose**: Creates TextGrid with V/UV annotations from PointProcess for soft phonation detection in DSI

**Usage**:
```r
pp <- sound$to_point_process_cc(pitch)
tg_vuv <- pp$to_textgrid_vuv(
  max_voiced_period = 0.02,    # 50 Hz minimum
  max_unvoiced_period = 0.01   # 100 Hz maximum
)
voiced_intervals <- sound$extract_intervals_where(tg_vuv, 1, "is equal to", "V", FALSE)
```

### 2. Sound$to_textgrid_silences() ✅ COMPLETE
**Status**: Fully functional with all 7 parameters
**Location**: R/sound-r6-new.R (lines 509-570)
**C++ Wrapper**: src/sound_wrappers.cpp (lines 1139-1167)
**Purpose**: Detects silences using native Praat function for AVQI analysis

**Key Feature**: Uses Praat's native `Sound_to_TextGrid_detectSilences()` from dwtools

**Parameters**:
- `min_pitch` (100 Hz) - Minimum pitch for intensity analysis
- `time_step` (0.0 = auto) - Time step for intensity
- `silence_threshold` (-25 dB) - **CRITICAL** - Silence detection sensitivity
- `min_silent_duration` (0.1s) - Minimum silence length
- `min_sounding_duration` (0.1s) - Minimum sound length
- `silent_label` ("silent") - Label for silent intervals
- `sounding_label` ("sounding") - Label for sounding intervals

**Usage**:
```r
tg_silences <- sound$to_textgrid_silences(
  min_pitch = 75,
  silence_threshold = -30.0,  # More sensitive for AVQI
  min_silent_duration = 0.2,
  min_sounding_duration = 0.3
)
```
