# Build Fix 2025-11-13 v4 - Roots s_description Missing Symbol

## Problem
Package build failed during installation with linking error:
```
symbol not found in flat namespace '__ZN11structRoots13s_descriptionE'
```

This demangled symbol is `structRoots::s_description`.

## Root Cause
The `Roots` class is defined using `oo_DEFINE_CLASS` and `oo_END_CLASS` macros in `Roots_def.h`. These macros declare a static field `Data_Description s_description` that must be defined in the corresponding `.cpp` file.

However, `Roots.cpp` is disabled (Roots.cpp.disabled) because it depends on CLAPACK/LAPACK for eigenvalue computations which are not included in this package.

The stub file `roots_stubs.cpp` used `Thing_implement()` macro but did not define the required `s_description` static field.

## Solution
Added definition of the `s_description` field in `roots_stubs.cpp`:

```cpp
// Provide the s_description field required by oo_DEFINE_CLASS  
Data_Description structRoots :: s_description = nullptr;
```

Setting it to `nullptr` is appropriate because:
1. The Roots functionality is disabled and will throw errors if called
2. The serialization methods (readText, writeText, etc.) are stubbed to throw errors
3. No actual serialization/deserialization will ever succeed for Roots objects

## Files Modified
- `src/roots_stubs.cpp`: Added `s_description` field definition
