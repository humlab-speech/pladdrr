# Build Fix - November 13, 2025 (v5)

## Problem Identified

The package failed to build due to errors in `table_wrappers.cpp`:
- Usage of undefined macros `BEGIN_RCPP_PRAAT` and `END_RCPP_PRAAT`
- Usage of undefined macro `GET_PRAAT_OBJECT`
- Incorrect usage of `autoSTRVEC` constructor
- Incorrect string conversion functions

## Changes Made

### src/table_wrappers.cpp
Rewrote all wrapper functions to use the standard pattern used in other wrapper files:
1. Replaced `BEGIN_RCPP_PRAAT` / `END_RCPP_PRAAT` macros with try-catch blocks
2. Replaced `GET_PRAAT_OBJECT` with `get_xptr_object<structTable>`
3. Fixed `autoSTRVEC` initialization to use `newSTRVECzero()`
4. Fixed string conversions:
   - Removed incorrect `.get()` calls on `conststring32` (which is already a pointer)
   - Used `Melder_peek8to32()` directly without storing in `autostring32`
5. Fixed `create_xptr_from_auto` usage
