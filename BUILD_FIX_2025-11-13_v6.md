# Build Fix Session - November 13, 2025 (v6)

## Issue Identified

The package build was failing due to compilation errors in `src/table_wrappers.cpp`:

### Errors Found:
1. **Use of undefined `newSTRVECzero` function** - Line 26
2. **Undefined `releaseToAmbiguousOwner()` method** - Line 29  
3. **Undefined `get_xptr_object` template function** - Multiple occurrences
4. **Missing template functions in `praat_xptr_utils.h`**

## Root Cause

The `table_wrappers.cpp` file was using non-existent helper functions:
- `get_xptr_object<T>()` - doesn't exist in `praat_xptr_utils.h`
- `newSTRVECzero()` - Praat internal function not properly wrapped
- `.releaseToAmbiguousOwner()` - incorrect method for string handling

## Fixes Applied

### 1. Fixed `table_create_with_column_names()` Function
**Before:**
```cpp
autoSTRVEC names = newSTRVECzero(columnNames.size());
for (int i = 0; i < columnNames.size(); i++) {
  autostring32 str = Melder_dup(Melder_peek8to32(Rcpp::as<std::string>(columnNames[i]).c_str()));
  names[i+1] = str.releaseToAmbiguousOwner();
}
autoTable table = Table_createWithColumnNames(numberOfRows, names.get());
```

**After:**
```cpp
autoTable table = Table_create(numberOfRows, columnNames.size());
for (int i = 0; i < columnNames.size(); i++) {
  conststring32 name = Melder_peek8to32(Rcpp::as<std::string>(columnNames[i]).c_str());
  Table_renameColumn_e(table.get(), i+1, name);
}
```

### 2. Replaced All `get_xptr_object<structTable>(xptr)` Calls

**Before:**
```cpp
Table table = get_xptr_object<structTable>(xptr);
return table->rows.size;
```

**After:**
```cpp
Rcpp::XPtr<structTable> ptr(xptr);
validate_xptr(ptr, "Table");
return ptr->rows.size;
```

This pattern was applied to all 18 functions in the file.

### 3. Updated Pointer Usage

Changed from:
```cpp
Table_getNumericValue_a(table, rowNumber, columnNumber)
```

To:
```cpp
Table_getNumericValue_a(ptr.get(), rowNumber, columnNumber)
```

When calling Praat C functions that expect raw pointers.

## Implementation Notes

### XPtr Pattern
The correct pattern for working with external pointers in this codebase is:

```cpp
Rcpp::XPtr<structType> ptr(xptr);  // Convert SEXP to XPtr
validate_xptr(ptr, "TypeName");     // Validate non-null
ptr->member                         // Access members directly
ptr.get()                           // Get raw pointer for C functions
```

### String Conversion
For converting R strings to Praat strings:
```cpp
conststring32 str = Melder_peek8to32(std::string.c_str());
```

For converting Praat strings to R strings:
```cpp
std::string result = Melder_peek32to8(conststring32);
```
