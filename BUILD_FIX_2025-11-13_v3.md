# Build Fix - November 13, 2025 (v3)

## Issue Identified

The package build was failing at the linking stage with the following error:

```
symbol not found in flat namespace '__ZN11structRoots12v1_writeTextEP16structMelderFile'
```

This indicated that the `structRoots::v1_writeText` virtual method was declared in the class definition but not implemented in `src/roots_stubs.cpp`.

## Root Cause

The `Daata` class (parent of `Roots`) has virtual methods for reading and writing objects:
- `v1_readText()` - for reading from text files  
- `v1_writeText()` - for writing to text files

The `roots_stubs.cpp` file implemented `v1_readText()` but was missing the `v1_writeText()` implementation, causing an undefined symbol error during linking.

## Fix Applied

Added the missing `v1_writeText()` method implementation to `src/roots_stubs.cpp`:

```cpp
void structRoots :: v1_writeText (MelderFile /* file */) {
	// Roots object cannot be written - functionality is disabled
	Melder_throw (U"Roots object cannot be written: functionality is disabled.");
}
```

This implementation:
1. Satisfies the linker requirement for the virtual method
2. Throws an error if called, since Roots functionality is disabled
3. Is consistent with the error-throwing approach used for other Roots stub functions

## Files Modified

- `src/roots_stubs.cpp` - Added `v1_writeText()` method implementation
