# Build Fix Session - November 15, 2025

## Problem
The R package `speaker` was failing to build with missing symbol errors during the link/load phase.

## Root Cause
Missing stub implementations for numerous Praat C++ functions that are referenced by the compiled code but not implemented because they require:
- CLAPACK/LAPACK (linear algebra)
- Full NUM2 implementation (numerical routines)
- GUI components (NO_GUI build)
- Interactive features (Editor, Demo, UiForm)
- File I/O libraries (FLAC, MP3, Ogg)

## Solution
Added stub functions to multiple files to provide symbols while throwing appropriate error messages when called:

### Files Modified

#### 1. `src/num2_stubs.cpp`
Added:
- `VECarea_from_rc()` - Area/reflection coefficient conversion
- `VECrc_from_area()` - Reverse conversion
- `VECsolveSparse_IHT()` - Sparse solution (throws error)
- `solveSparse_IHT_VEC()` - Wrapper version
- `windowShape_into_VEC()` - Window shaping function
- `kSound_windowShape` enum definition
