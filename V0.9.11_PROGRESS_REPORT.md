### Changes Made to getting-started.Rmd

1. **Introduction** - Updated to mention "R6 object-oriented interface"

2. **Sound Loading**:
   - `read_sound()` → `Sound$new()`
   - Channel indexing: 0-based → 1-based

3. **Sound Properties**:
   - `get_duration()` → `sound$get_duration()`
   - `get_sampling_rate()` → `sound$get_sampling_frequency()`
   - `get_n_samples()` → `sound$get_number_of_samples()`
   - `get_n_channels()` → `sound$get_number_of_channels()`

4. **Pitch Analysis**:
   - `extract_pitch()` → `sound$to_pitch()`
   - `get_mean_pitch()` → `pitch$get_mean()`
   - `get_min_pitch()` → `pitch$get_minimum()`
   - `get_max_pitch()` → `pitch$get_maximum()`
   - `get_pitch_at_time()` → `pitch$get_value_at_time()`

5. **Formant Analysis**:
   - `extract_formants()` → `sound$to_formant_burg()`
   - Parameter: `max_formant` → `max_frequency`
   - Parameter: `n_formants` → `max_formants`
   - `get_formant_at_time()` → `formants$get_value_at_time()`
   - `get_mean_formant()` → `formants$get_mean()`
   - `summary(formants)` → `formants` (R6 print method)

6. **Intensity Analysis**:
   - `extract_intensity()` → `sound$to_intensity()`
   - `get_mean_intensity()` → `intensity$get_mean()`
   - `get_min_intensity()` → `intensity$get_minimum()`
   - `get_max_intensity()` → `intensity$get_maximum()`
   - `get_sd_intensity()` → `intensity$get_standard_deviation()`
   - `get_intensity_at_time()` → `intensity$get_value_at_time()`

7. **Data Frames**:
   - `as.data.frame(formants)` → `formants$as_data_frame()`
   - `as.data.frame(intensity)` → `intensity$as_data_frame()`

8. **Complete Workflow**:
   - Updated entire example workflow to use R6 throughout

9. **Praat Comparison**:
   - Updated to show R6 syntax matches Praat better

10. **Advanced Topics**:
    - Updated all parameter names to match R6 interface
