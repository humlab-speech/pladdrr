# Build Fix 2025-11-14 - Missing VECrc_from_lpc Symbol

## Problem
The package was failing to load with the error:
```
symbol not found in flat namespace '__Z14VECrc_from_lpc6vectorIdE11constvectorIdE'
```

This is the C++ mangled name for the function `VECrc_from_lpc(constvector<double>)`.

## Root Cause
The LPC module requires the `VECrc_from_lpc` function which converts LPC coefficients to reflection coefficients. This function is part of NUM2.cpp in the Praat source, but we were using stub files to avoid dependencies on CLAPACK and GSL.

## Solution
Added a stub for `VECrc_from_lpc` in `src/num2_stubs.cpp`:

```cpp
// Stub for VECrc_from_lpc - converts LPC coefficients to reflection coefficients
// This is a complex numerical algorithm that would need full NUM2 implementation
autoVEC VECrc_from_lpc (constvector<double> lpc) {
    Melder_throw (U"VECrc_from_lpc is not available in this build (requires full NUM2 implementation).");
}
```

Also added the necessary include:
```cpp
#include "praat.github.io/melder/VEC.h"
```
