# Evaluate a vector Praat expression

Evaluate a vector Praat expression

## Usage

``` r
praat_eval_vector(expression)
```

## Arguments

- expression:

  Character string containing a Praat vector formula

## Value

Numeric vector

## Examples

``` r
# Create vector
vec <- praat_eval_vector("{ 1, 2, 3, 4, 5 }")
```
