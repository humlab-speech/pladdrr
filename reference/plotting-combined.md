# Combined Visualization Functions

Convenience functions for common multi-object visualizations that
combine multiple Praat objects in a single plot. These replicate common
Praat plotting patterns using ggplot2 and patchwork/gridExtra.

## Value

This is a documentation-only overview; see the individual functions
(e.g.
[`plot_sound_pitch`](https://humlab-speech.github.io/pladdrr/reference/plot_sound_pitch.md),
[`plot_textgrid_sound`](https://humlab-speech.github.io/pladdrr/reference/plot_textgrid_sound.md))
for their return values.
