# Build Fix - November 13, 2025 (v2)

## Issue
Package failed to load with symbol not found error:
```
symbol not found in flat namespace '__ZN11structRoots11v1_readTextEP20structMelderReadTexti'
```

## Root Cause
The `roots_stubs.cpp` file was missing the required virtual method `v1_readText` which is declared in the base class `Daata` (Data).

## Fix Applied
Added the missing `v1_readText` virtual method implementation to `roots_stubs.cpp`:

```cpp
void structRoots :: v1_readText (MelderReadText /* text */, int /* formatVersion */) {
	// Roots object cannot be read - functionality is disabled
	// We leave the object in an empty state
	numberOfRoots = 0;
	roots = nullptr;
}
```

## Key Points
- Virtual method cannot throw exceptions during object construction/deserialization
- Instead, the stub initializes the object to an empty/safe state
- This allows the package to compile and link successfully
- Any actual use of Roots functionality will still throw appropriate errors via the other stub functions

## Files Modified
- `src/roots_stubs.cpp` - Added v1_readText stub implementation

## Status
Build issue resolved. Package should now compile and load successfully.
